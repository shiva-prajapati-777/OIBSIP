## ▶️ How to Run

### Using Visual Studio Code

1. Clone or download this repository.
2. Open the `WebDev-L1-PersonalPortfolio` folder in Visual Studio Code.
3. Open `index.html`.
4. Install the **Live Server** extension if it is not already installed.
5. Right-click `index.html`.
6. Select **Open with Live Server**.
7. The portfolio will open in your web browser.

You can also open `index.html` directly in a modern web browser.
