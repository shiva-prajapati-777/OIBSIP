## 🎯 Objective

Build a fully functional browser-based calculator with a user-friendly button interface using HTML5, CSS3, and Vanilla JavaScript.

## ✨ Features

- Addition, subtraction, multiplication and division
- Percentage calculation
- Decimal number support
- Clear / All Clear button
- Backspace / Delete
- Division-by-zero error handling
- Modulus-by-zero error handling
- Operator chaining
- Calculation history
- Keyboard support
- Responsive design
- Interactive button effects
- Modern glassmorphism UI
- Toast notifications
- Animated interface

## 🚫 No `eval()`

The calculator does not use JavaScript's `eval()` function.

All calculations are handled using custom JavaScript logic with variables, conditionals, and a `switch` statement.

## 🧪 Testing

The calculator was tested for:

- Basic arithmetic operations
- Decimal calculations
- Percentage calculations
- Operator chaining
- Backspace functionality
- Clear functionality
- Division by zero
- Responsive behavior
- Keyboard input

Example:

```text
5 + 3 = 8
10 - 4 = 6
6 × 7 = 42
20 ÷ 5 = 4
```

Division by zero is handled with an error message.

## 🚀 How to Run

1. Open the project folder in Visual Studio Code.
2. Open `index.html`.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

You can also open `index.html` directly in a modern web browser.
